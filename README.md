# The GitHub Cheat Sheet for Vibe Coders

**👉 Open the guide: https://unnati-23.github.io/github-cheat-sheet/**

A free one-page guide to Git and GitHub for people who learned to build with AI. It covers the exact Claude prompts for:

1. **Saving your progress** (commit and push)
2. **Undoing a broken change** (go back to the last commit that worked)
3. **Testing a feature safely** (branch, then merge or delete)

Plus clone, tags, and a one-time setup.

## The 7 words

| Word | What it means |
|---|---|
| **Commit** | A snapshot of your files, linked to the snapshot before it. Your app's timeline. |
| **Push** | Uploads your commits to GitHub so your history lives online. |
| **Clone** | Copies a project and its history from GitHub to your computer. |
| **Branch** | A second timeline that splits off, so you can try things safely. |
| **Merge** | Brings a branch that worked back into your main timeline. |
| **Delete a branch** | Throws away a branch that didn't work. |
| **Tag** | A name like `v1` on one exact commit, so you can find it any time. |

## If you remember one thing

Tell Claude: **"Commit and push."**
